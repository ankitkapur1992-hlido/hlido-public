Help us build the public failure database for AI agents. Every submission is reviewed by Hlido staff before publication.

Before you submit — what counts as evidence:
  • Screenshots — the agent's UI, error message, or output, with timestamps visible.
  • Log dumps — pasted to a public gist or pastebin, with API request/response pairs and any reasoning traces.
  • Reproduction steps — minimal, numbered, deterministic where possible.
  • Recordings — screen recordings (Loom, Asciinema for CLI) showing the failure end-to-end.
  • Public posts — the vendor's own status page, GitHub issue, or social-media acknowledgement.

Read How to write a good incident report for detail. Submissions are reviewed before publication; we'll email you within 7 days with the decision. When we publish, the vendor gets 48 hours to respond and a re-test is queued. False or malicious reports may result in submission rights being revoked.
